# Humanizer: remove AI writing patterns

Rewrite AI-sounding text so it reads like a real person, not an AI chatbot. Keep what it says. Do not make anything up.

## Key Rules
1. Eliminate decorative emojis (✨, 🚀, 💡, 🌟, 👉, etc.) from UI text, alerts, and toasts.
2. Remove salesy / hyperbolic AI words ("revolusioner", "terpadu", "tanpa kompromi", "solusi mutakhir", "inspiratif", "menghadirkan ekosistem").
3. Drop one-line closers and dramatic statements ("Sistem bebas salin ulang! Ibu tidak perlu menulis ulang berkali-kali!").
4. Use plain, direct, and natural Indonesian as used by real teachers and school staff (bahasa wajar guru sekolah: ringkas, lugas, santun, tidak berlebihan).
5. State facts and functional directions plainly.
